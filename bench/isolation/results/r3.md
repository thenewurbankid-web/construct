## Notes (written after the run)

- **The fixer removed every tsc failure.** No r3 row ends in tsc. Each of the 11 tsc-failing final rows in the
  four baselines became either a pass (D t05, D t10, H t08, E t05) or a check failure (real logic gaps the tsc
  error had hidden; e.g. D t07 r3.jsonl:19, E t10 r3.jsonl:46). Per candidate, the fixer turned 4 tsc failures
  into passes and 14 into check failures.
- **Fragments are not wiring, and the fixer leaves them alone.** C t05/t08 (r3.jsonl:5, :8) and H t04/t05
  (r3.jsonl:28, :29) are unchanged.
- **The cross-feature rule did real work.** D t05's direct import of `features/picks/store/picksStore` was
  rewritten to `../../picks` (the `_scope` index.ts), and then React was added (r3.jsonl:17, `fix.log`).
- **What is left is logic and intent, not wiring:** t07 (heading/remove buttons), t10 (paging controls, C and E),
  and t12 (genre filter, 3 of 4 arms).
- The fixer used TypeScript's language service through `projectLanguageService` (packages/engine/tsFileMove.mjs),
  with the root node_modules as a read-only root so `react` resolves. The scope rule falls back to a local copy of
  Line's moduleScope/importableFor index rule, because the harness workspace is not a Line project.
