## Done on 2026-10-14

- `e55a803` Each rewrite taken back carries a `diagnosis`: cause (atom, mutation, kind,
  transform, unknown), why, a proposed fix, and the probe input that shows it. The atom's
  catalog form is run on its own: every argument of its declared type, then the first of
  any kind, then all of any kind.
- `071ad0b` Where the bare form differs, the atom is also called directly, so a fault in
  the call the transform writes is not blamed on the atom.
- `aee9cdb` Generated text includes edge strings (spaces on one side, tabs, line breaks,
  mixed case, non-ASCII, separators). Same run time.
- `f970aa5` `replaceFirst` only where the pattern is text or a RegExp literal without g
  (read from the catalog: params checked with `ngregex` and never `gregex`). Fixed
  `csvFileName` and `csvCell`.
- `833039f` The probe types every argument as the atom declares it, with Smith's own type
  names (`Lazy`, `Visit`, `SortOrder`) resolved; RegExp arguments are generated.
- `9a2dd32` `sortedBy` only for no order or an inline function whose declared length is
  not 1 (params checked only with `cmp`). A sort by a named function stays a sort.

Checked by putting faults in on purpose (scratch copies of the runtime): a loose `equals`
