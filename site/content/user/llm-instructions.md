Any AI model can drive Construct through its installed command-line tool. Give it the prompt below and it will orient with the read-only commands, change code with the blocks instead of by hand, and loop on `construct validate` until it is clean. The prompt is about behaviour and commands rather than a copy of the rules, so it does not go stale when a rule changes.
