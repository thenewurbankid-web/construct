Vision Architect is a separate tool that reads front-end web pages, cuts each one into pieces, describes every piece in plain English and rebuilds it as a small, typed, tested component. The finished components are kept in a searchable library, and each time it works through a page that is recorded as a run.

This page is a snapshot: it shows what was recorded at the time given below and does not update by itself. It lists the recent runs and the components in the library.

**Early snapshot.** This is a first version. The "Stored" column does not yet have its own "Extended" count (two pieces were extended into new component versions and show only in the library history), and a run with no report yet is shown as "running". Both are being fixed in the next update.
