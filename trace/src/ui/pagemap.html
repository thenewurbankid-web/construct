How ids and decisions work

Every node's id is positional: it is made from the file name, the line and column and the tag path. So a whitespace-only edit, or any edit that moves lines, changes ids and orphans the decisions made on them; the count is in the summary line and they are listed under States & flows, where you can drop one or re-attach it (select the node now at that place and decide again). Two identical texts in different places are two parts. Decisions never change the design; the marked copy and the page replacement are separate, explicit steps, and a replaced page is kept as a backup that is never overwritten.
