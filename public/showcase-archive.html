Code as English (archived version)

This is a reconstruction of the earlier standalone showcase page, kept for reference. The live, consolidated version (with editable code, English block-by-block output, and the browser-LLM chat) is now at /demo.html.

page.ts
Page will check text "hello", and if text is equal to "hello" → 'static'
show the code 
page.will().checkText(new PageText('hello')).and().if().text().is().equalTo(new PageText('hello'))
// -> 'static'
form.ts
Form will check field 42, and if value is greater than 10 → 'valid'
show the code 
form.will().checkField(new FieldValue(42)).and().if().value().is().greaterThan(new FieldValue(10))
// -> 'valid'
Untitled-1 (speed)
Calculate speed, using distance 100 and time 20 → 5
show the code 
calculateSpeed().using().distance(100).and().time(20)
// -> 5
Untitled-1 (assertion)
Check 1, is greater than 2, then it is false → true
show the code 
check(1).is().greaterThan(2).then().itIs(false)
// -> true (1 is not greater than 2, so the expectation holds)
