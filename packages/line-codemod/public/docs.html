Reference

Every export in smith, with its actual source (not a signature summary) and what it's for. Nothing here is invented for this page — each block is copied directly from src/index.ts, and every usage example below has been compiled under --strict and run.

Chain

Connector words. Every method just return this — pure structure, no meaning of its own. Extend it once; every fluent builder in your app shares these instead of redefining them.

export abstract class Chain {
  and(): this {
    return this;
  }

  but(): this {
    return this;
  }

  also(): this {
    return this;
  }

  if(): this {
    return this;
  }

  then(): this {
    return this;
  }

  is(): this {
    return this;
  }
}

if() is a method, not a function — "if" is a reserved word in JS/TS and can only exist as a property name.

Organism

The one connector that starts a chain at your entry point.

export abstract class Organism {

Comparable<T>

Implement compareTo() once per value type; every comparison method comes free. The single place raw ===/>/< is allowed to exist — everywhere else calls one of these instead of repeating that logic per type.

export abstract class Comparable<T> {
  protected abstract compareTo(other: T): number;

  equals(other: T): boolean {
    return this.compareTo(other) === 0;
  }

  greaterThan(other: T): boolean {
    return this.compareTo(other) > 0;
  }

  lessThan(other: T): boolean {
    return this.compareTo(other) < 0;
  }

  greaterThanOrEqual(other: T): boolean {
    return this.compareTo(other) >= 0;
  }

  lessThanOrEqual(other: T): boolean {
    return this.compareTo(other) <= 0;
  }
}

Negative = less than, zero = equal, positive = greater than — same contract as Java's Comparable or Array.prototype.sort's comparator.

Conditional / Subject / Clause / ifIt()

The branch-chain system — what the atomic-codemod tool's transform actually generates. It turns if (subject.method(arg)) { return a; } else { return b; } into ifIt(subject).method(arg).thenItIs(a).orelseIs(b), with zero closures and every method zero- or one-arg, same rule as Comparable/Chain.

equals()/greaterThan()/etc. delegate to the same-named method on the wrapped subject — ifIt(x).equals(y) behaves exactly like x.equals(y), just deferred through the chain. isSameAs()/isEqualTo() are the raw === alternative, for primitives without their own .equals() (e.g. ifIt(rule).isSameAs(null)). 

export class Conditional<T> {
  constructor(readonly matched: boolean, readonly result: T | undefined) {}

  orifIt<S>(subject: S): Subject<T, S> {
    return new Subject<T, S>(this, subject);
  }

  orelseIs(value: T): T {
    return this.matched ? (this.result as T) : value;
  }
}

export class Subject<T, S> {
  constructor(readonly parent: Conditional<T> | null, readonly value: S) {}

  equals(other: unknown): Clause<T, S> {
    return new Clause<T, S>(this.parent, (this.value as any).equals(other));
  }

  greaterThan(other: unknown): Clause<T, S> {
    return new Clause<T, S>(this.parent, (this.value as any).greaterThan(other));
  }

  lessThan(other: unknown): Clause<T, S> {
    return new Clause<T, S>(this.parent, (this.value as any).lessThan(other));
  }

  greaterThanOrEqual(other: unknown): Clause<T, S> {
    return new Clause<T, S>(this.parent, (this.value as any).greaterThanOrEqual(other));
  }

  lessThanOrEqual(other: unknown): Clause<T, S> {
    return new Clause<T, S>(this.parent, (this.value as any).lessThanOrEqual(other));
  }

  isSameAs(other: S): Clause<T, S> {
    return new Clause<T, S>(this.parent, this.value === other);
  }

  isEqualTo(other: S): Clause<T, S> {
    return new Clause<T, S>(this.parent, this.value === other);
  }

  // Only callable when S is boolean -- for a compound and(...)/or(...)
  // condition that's already a yes/no value, with no "other" to compare.
  isTrue(this: Subject<T, boolean>): Clause<T, boolean> {
    return new Clause<T, boolean>(this.parent, this.value);
  }
}

export class Clause<T, S> {
  constructor(readonly parent: Conditional<T> | null, readonly matched: boolean) {}

  thenItIs(value: T): Conditional<T> {
    if (this.parent && this.parent.matched) {
      return this.parent; // an earlier clause already matched -- keep its result
    }
    return new Conditional<T>(this.matched, this.matched ? value : undefined);
  }
}

export function ifIt<T, S>(subject: S): Subject<T, S> {
  return new Subject<T, S>(null, subject);
}

and() / or()

&&/|| as free functions, not methods. a.and(b) would assume a has its own .and() method, but &&/|| almost always combine plain booleans (the result of a comparison), and booleans have no such method. 

export function and(a: boolean, b: boolean): boolean {
  return a && b;
}

export function or(a: boolean, b: boolean): boolean {
  return a || b;
}

Putting it together

Two verified examples — Chain/Organism/Comparable, then the branch-chain system on its own.

import { Chain, Organism, Comparable } from 'smith';

class PageText extends Comparable<PageText> {
  constructor(private readonly value: string) { super(); }
  protected compareTo(other: PageText): number {
    return this.value.localeCompare(other.value);
  }
}

type TextResult = 'static' | 'dynamic';

class TextCheck extends Chain {
  constructor(private readonly current: PageText) { super(); }
  equalTo(expected: PageText): TextResult {
    if (this.current.equals(expected)) {
      return 'static';
    } else {
      return 'dynamic';
    }
  }
}

class Page extends Organism {
  checkText(current: PageText): TextCheck {
    return new TextCheck(current);
  }
}

const page = new Page();
page.will().checkText(new PageText('hello')).and().if().is().equalTo(new PageText('hello'));
// -> 'static'
compiled under --strict, run, printed 'static'
import { ifIt, and } from 'smith';

// subject.method(arg) -> ifIt(subject).method(arg) -- this is exactly
// what the atomic-codemod tool generates from:
//   return rule == null ? 'unrated' : value === rule.expected ? 'valid' : 'invalid';
function validateField(rule: Rule, value: Comparable): string {
  const expected = rule?.expected.value ?? null;
  return ifIt<string, Rule>(rule).equals(null).thenItIs('unrated')
    .orifIt<Comparable>(value).equals(expected).thenItIs('valid')
    .orelseIs('invalid');
}

validateField(new Rule(null), new Comparable('anything'));       // 'unrated'
validateField(new Rule({ expected: 'red' }), new Comparable('red'));  // 'valid'
validateField(new Rule({ expected: 'red' }), new Comparable('blue')); // 'invalid'

function isWithinRange(value: number, min: number, max: number): boolean {
  return and(value >= min, value <= max);
}

isWithinRange(5, 0, 10);  // true
isWithinRange(15, 0, 10); // false
