Embedding fine-tune data

Every time "Find similar shapes" runs, the (shape-A, shape-B, same-or-not) pairs it finds are logged here automatically — a free byproduct of the deterministic AST detection already running. Nothing is trained yet; this is the dataset a future fine-tune of nomic-embed-text would learn from, so the embedding model itself eventually recognizes AST shape, not just word similarity.

Why not just fine-tune now?

Fine-tuning needs a real training pipeline (sentence-transformers, GPU time) and, more importantly, enough pairs to generalize from — a handful of examples from one small codebase would just memorize these specific snippets, not learn "AST shape" as a concept. The plan is: keep collecting pairs for free as the atom library grows (every new organism adds more positive/negative examples automatically), and once there's a meaningfully sized dataset, run the fine-tune below. Until then, the deterministic AST comparison in module-scanner.js already does this job exactly and for free — the fine-tuned model's win, if it works, would be catching near-shapes that aren't byte-identical after normalization (e.g. an extra intermediate variable, a slightly different control-flow ordering) which today's exact-fingerprint match misses.

The fine-tuning script (documented, not run or verified here)

Needs Python + pip install sentence-transformers — I have no way to run or verify a real training job from this environment, so treat this as a documented starting point, not a tested result: 
from sentence_transformers import SentenceTransformer, InputExample, losses
from torch.utils.data import DataLoader
import json

model = SentenceTransformer('nomic-ai/nomic-embed-text-v1.5')

examples = []
with open('pairs.jsonl') as f:
    for line in f:
        row = json.loads(line)
        examples.append(InputExample(texts=[row['textA'], row['textB']], label=float(row['label'])))

loader = DataLoader(examples, shuffle=True, batch_size=8)
loss = losses.ContrastiveLoss(model)
model.fit(train_objectives=[(loader, loss)], epochs=3, warmup_steps=10)
model.save('nomic-embed-code-shape-v1')
