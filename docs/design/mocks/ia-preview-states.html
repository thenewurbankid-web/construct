Starting

Outside the workspace

This project is not inside the workspace root, so the Cockpit will not start a server for it.

When it goes wrong

Server stopped

Port 5173 is in use by another process.

Click-to-source is off

Your app does not load the Cockpit preview plugin. Tree, impact and source still work.

plugins: [constructPreview(), react()]
