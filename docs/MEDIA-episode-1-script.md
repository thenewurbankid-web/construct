## Ground rules
- Nothing is faked: if a step has no working UI, the video stops before it and we file a bug instead.
- No real emails, tokens or repository names on screen; sample data only.
- 1280x720, under 6 MB, captions burned into the page, transcript on the website page.
- Steps 3-4 depend on the UI offering "start a new project" from the gate; if it doesn't, the script says so and uses the closest real path.
