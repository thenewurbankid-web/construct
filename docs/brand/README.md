# Brand marks

Four marks, one grammar: pills, and at most one lit (gradient) element.

| Mark | File | Means |
|---|---|---|
| **Line** | `line.svg` | The whole package: two pills, one solid, one outlined. Docs website and umbrella. |
| **Construct** | `construct.svg` | The framework: The Construct, the empty white room: just a pill with nothing in it. |
| **Cockpit** | `cockpit.svg` | The UI / IDE: a toggle capsule with a lit knob (you choose Mechanical or AI). |
| **CLI** | `cli.svg` | The command line: a prompt pill and a lit cursor pill. Unnamed: no wordmark, it is just `construct`. |

Wordmarks are set in capitals with wide tracking (`letter-spacing: .3em`, weight 600). The mark draws in
`currentColor` with the accent gradient `#8fb0ff` to `#4b63f5`; the standalone files switch ink for dark mode.
